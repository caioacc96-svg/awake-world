# AWAKE WORLD 0.6 — MVD CANON

**Status:** CANONICAL DEVELOPMENT CONTRACT  
**Milestone:** `0.6.0-dev` — **THE LIVING QUARTER**  
**Baseline:** frozen release `v0.5.0 GLOBAL`  
**Method:** MVD — Minimum Viable Design  
**Identity:** `awake/world — THE LIVING NETWORK`

This document extends, and does not replace, the canonical Interaction + Experience Bible v1.

**Execution extension:** `docs/AWAKE_WORLD_06_MVD_3_TO_9_EXECUTION_CANON.md` is the authoritative phase-by-phase contract for MVD-3 through MVD-9. The extension preserves this document's permanent laws and resolves the post-MVD-5 sequence through the 0.6 release candidate.

## 1. Decision

Awake World 0.6 is not a room-by-room beautification pass.

The world is treated as one coherent urban organism:

```text
WORLD
→ DISTRICT
→ BUILDING
→ SPACE
→ OBJECT
→ INTERACTION
```

Every environment inherits the same visual DNA. Each environment then expresses a local dialect through function, density, composition, secondary materials, lighting, props, vegetation, sound and ambient behavior.

**One world. One language. Multiple dialects.**

A local design that looks attractive in isolation but does not look like Awake World fails acceptance.

## 2. Permanent laws

- **THE SPACE IS THE INTERFACE**
- **SUBTLE LIFE**
- **PERCEIVED COMPLEXITY > RAW COMPLEXITY**
- **HIGH-END EXPERIENCE / LOW-COST ARCHITECTURE**
- single-player first / multiplayer-ready
- stylized premium
- contemporary architecture + integrated nature + quiet technology + subtle digital nostalgia
- no neon/cyberpunk shorthand for technology
- no corporate-metaverse visual language
- no asset-store salad
- no AI slop
- no HUD-first solution where the world can communicate the same state

## 3. MVD operating method

MVD is used here as a repeated design loop:

```text
DESIGN
→ IMPLEMENT ACROSS THE WHOLE WORLD
→ MEASURE IN BUILD + GOLDENS
→ LEARN
→ REVISE THE SHARED SYSTEM
```

"Minimum" means the smallest coherent layer that can be judged in the running product. It does **not** mean temporary off-canon art.

Every iteration must:

1. cross all applicable environments;
2. preserve a working executable;
3. produce deterministic visual evidence;
4. be judged against the Bible and this contract;
5. prefer system-level improvement over local exceptions.

## 4. MVD sequence for 0.6

### MVD-0 — Visual grammar foundation

Across the entire Awake Quarter:

- centralize global visual DNA;
- centralize per-space visual profiles;
- remove palette ownership from individual scene code;
- make thresholds inherit the destination space's visual signature;
- normalize off-canon architecture labels;
- begin `0.6.0-dev` without changing the frozen `v0.5.0` release.

**Acceptance:** every registered space has exactly one visual profile and uses the shared visual system.

### MVD-1 — Massing + scale

Across all environments simultaneously:

- architectural scale;
- silhouette;
- paths and negative space;
- building hierarchy;
- street/building continuity;
- avatar-to-world proportion;
- landmark readability.

**Acceptance:** grayscale screenshots remain recognizable by space without labels.

### MVD-2 — Material + light

Across all environments simultaneously:

- material hierarchy;
- surface response;
- window/glass language;
- warm/cool balance;
- day/dusk/night coherence;
- weather response;
- local lighting dialects.

**Acceptance:** any random screenshot belongs unmistakably to Awake World while major spaces remain distinguishable.

### MVD-2.1 — Visual foundation acceptance pass

MVD-2 is not considered human-accepted merely because palette/light automation passes. Before MVD-3, the authored world must also clear a visual foundation pass across every space:

- continuous architectural ground instead of debug-like tile checkerboarding;
- layered architectural assemblies instead of raw cuboids;
- contact shadow and facade depth;
- glass framed as architecture, not transparent color fill;
- restrained large-format joints and perimeter detailing;
- vegetation integrated as architectural landscape clusters;
- tighter composition so the authored environment dominates the frame;
- MVD-1 footprints, collisions, circulation and landmarks remain unchanged.

**Acceptance:** a static screenshot must read as an authored premium diorama before NPC motion, ambient animation or MVD-3 life is used to create interest.

### MVD-2.2 — Spatial depth acceptance pass

MVD-2.1 establishes the authored visual foundation. MVD-2.2 adds architectural depth before life/animation:

- stairs are stepped geometry tied to a real raised plane;
- civic platforms, decks and terraces introduce multiple visible elevations;
- tall structures gain lower/upper mass separation and setback while staying inside the MVD-1 footprint;
- floor reveals, parapets, roof layers and support piers create readable vertical hierarchy;
- elevated elements cast their own isometric overlap/shadow relationships;
- every space receives a distinct vertical composition rather than the same extrusion recipe;
- navigation remains on the canonical MVD-1 plane until a later explicit traversal phase; MVD-2.2 must not silently change collision or pathfinding.

**Acceptance:** static renders must communicate at least three depth cues — elevation change, overlap/setback and structural support — before MVD-3 ambient life is allowed to carry the scene.

### MVD-3 — Subtle life

Across all environments simultaneously:

- vegetation;
- asynchronous micro-motion;
- screens and architectural state;
- recurring NPC purpose;
- pets;
- room tone;
- microevents;
- signs of occupancy.

**Acceptance:** when the player stops, something is always quietly continuing without becoming spectacle.

### MVD-4 — Spatial interaction integration

Across all environments simultaneously:

- contextual acknowledgment;
- thresholds;
- interaction affordance;
- diegetic status;
- camera grammar;
- transitions;
- anchored UI.

**Acceptance:** removing conventional HUD does not make the world unintelligible.

### MVD-5 — Human acceptance + foundation golden freeze

- deterministic golden set across representative spaces, times and weather;
- screenshot review against canon;
- movement/camera/interaction feel check;
- regression gates;
- performance check;
- final visual consistency pass.

MVD-5 freezes the accepted **foundation grammar** from MVD-1 through MVD-4. It is not the final 0.6 release freeze.

**Acceptance:** the world passes both automated gates and the human question: **does this feel like a place?**

### MVD-6 → MVD-9 — 0.6 completion sequence

The detailed contracts live in `docs/AWAKE_WORLD_06_MVD_3_TO_9_EXECUTION_CANON.md`.

- **MVD-6 — Multi-Level Traversal:** converts selected visual elevation into real authored traversal.
- **MVD-7 — Social + Work Surfaces:** makes the space itself the work/social interface.
- **MVD-8 — World Coherence + Production Hardening:** performance, reliability, soak and UX hardening.
- **MVD-9 — 0.6 Release Candidate + Final Golden Freeze:** full product acceptance and final 0.6 candidate freeze.

## 5. Shared visual DNA

The shared system owns:

- architectural proportions;
- base material family;
- surface contrast;
- shadow treatment;
- glass treatment;
- vegetation language;
- signage and typography;
- world-space affordances;
- light behavior;
- ambient-motion amplitude;
- weather response;
- global density limits;
- transition grammar.

No space may privately redefine these fundamentals.

## 6. Local dialects

| Space | Canonical dialect |
| --- | --- |
| Awake Quarter | calm urban continuity, legible circulation, restrained landmarks |
| Central Plaza | social garden, crossing paths, open civic scale |
| The Observatory | contemplative, broad, glass/stone/wood, quiet technology |
| The Grid | precise, modular, ordered, operational |
| Twin Core | premium dev laboratory, hardware/software, dense but controlled |
| Trinity Lab | collaborative research, warmer, experimental, porous |
| The Garage | workshop, utility, tactile industrial character |
| Kawaii Garden | nature, softness, intimacy, playful detail under restraint |
| The Pit | social brutalism, low light, energetic density without cyberpunk |
| The Glasshouse | transparency, vegetation, diffuse natural light |

The identity of a space must come from composition and behavior first, color second.

## 7. Global acceptance rule

> A screenshot from any point in Awake World must look unmistakably part of the same universe, while no major environment should feel interchangeable with another.

## 8. Frozen baseline rule

`v0.5.0` is immutable.

All 0.6 work occurs after the released baseline. Published tag and release assets are never moved or overwritten.
