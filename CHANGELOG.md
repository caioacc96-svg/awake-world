# Changelog

- Started the 0.6 visual-development cycle from the frozen v0.5.0 GLOBAL baseline.
- Added the canonical MVD contract for cross-world design iterations.
- Added centralized global/per-space visual profiles so all environments evolve through one authored system.

- Added fixed-step actor runtime with acceleration, deceleration, normalized diagonals, smooth reversal, collision slide, interpolation and walk/run state.
- Added contextual camera controller and profile-driven space transition orchestrator.
- Added deterministic world seed, replay recorder/player and automated gameplay drivers.
- Added schedule/FSM/utility NPC and pet behavior with weather, time and simulation-LOD response.
- Added seeded ambient-life, layered audio response, weather-aware presentation and data-driven space profiles.
- Added WorldState schema 6 migration, atomic save, backup/recovery and corruption handling.
- Added F3 world inspection controls, diagnostics export and runtime observability.
- Added Linux fast gates, Windows Qt/offscreen validation, visual regression, PyInstaller packaging and packaged executable smoke.
